# 夸一夸 · 小程序交互原型

当前推荐入口：**http://127.0.0.1:8896/#home**

产品范围以 [产品需求文档 PRD v1.1](docs/产品方案-v1.0.md) 为准，首页视觉以 [9 月 29 日首页参考图](design/home-reference-2026-09-29.png) 为准，其余页面以 [创作与记录 UI](design/ui-v2-creation-and-records.png) 和 [我的与套餐 UI](design/ui-v2-account-and-plan.png) 为准。当前为用户端网页交互原型，不是已上线微信小程序。

## 体验内容

- 五类场景创作：首页不显示分类；“我的 → 夸赞场景”可切换孩子成长、工作日常、学习探索、兴趣生活、日常美好，默认孩子成长并按账号保存。首次进入为空白草稿，文本框下方直接衔接生成按钮。
- 五类场景统一使用“总 Prompt＋场景 Prompt”，完整原文见[海报 Prompt 总规范](docs/kua_yi_kua_poster_prompts.md)，业务映射与接入见 PRD 第十节。每张照片提取事实、场景维度、闪光标签、主辅关键词和对应话术，海报展示主关键词＋话术；原型仍为占位生成，尚未执行此规范。
- 海报提示词要求底部展示“累计打卡 X 天 · 连续打卡 Y 天”，使用服务端按成功日统计的账号数据；当前原型海报尚未接入此统计展示。
- 上传 1–6 张真实照片；配文草稿、制作任务和成果保存在当前浏览器。
- 提交成功弹窗提供“查看进度 / 继续记录”；制作状态集中在“夸夸集”，没有独立制作中页面。记录展示提交时间与约 5 分钟预期，失败可重试。当前浏览器按每次提交 / 重试的时间模拟 5 分钟完成；关闭页面后再次打开会按经过时间恢复结果，并非服务端后台任务。失败状态由验收夹具驱动。
- 多图逐张配夸赞，再合成一张海报、计 1 次；当前各图文案为按分类和顺序提供的交互占位内容，尚未识图。默认 3:2 横版 Canvas 海报（1500 × 1000）、PNG 下载及分享预览；不替用户发送给他人。
- 关于我：添加家人、经历和表达偏好；新增、编辑、删除、停用、控制资料用途。
- 结果页“记住它”先展示原始配文及用途，确认后才入库；生成内容不会自动写成个人事实。
- 包月套餐：30 次／30 天的评审建议，价格待定；演示开通不付款，失败释放次数，续购／到期规则可查看。
- “使用帮助”内可切换两个隔离的本机账号，检查草稿、资料、任务和额度隔离。

## 明确边界

真实微信登录、AI 识图与生成、语义知识检索、服务端账号鉴权、云同步、微信分享与支付均未接入。当前文案根据分类与配文做演示，部分表达偏好可改变示例长短，不代表已经实现 AI 个性化。

本机两个账号用于验证交互隔离，不具备生产安全边界。图片压缩后写入浏览器存储；空间不足时提示保存失败并保留已有状态。

资料在制作期间撤回或修改时，原结果不能继续完成；可以按新资料状态重试。不使用资料时仍可正常制作。

## 图片处理与新海报方向

- 视觉方向见 [多图海报效果稿 v2](design/poster-editorial-v2.png) 与 [处理流程说明](design/poster-editorial-v2.md)。生成稿展示智能主体提取与背景融合的目标效果，不代表任意上传已经接入图像服务。
- 网页通过 `photo-processing.js` 在排版前做有限曝光校正、轻度色调归一和比例分析；保留原图副本和索引，可能严重切掉内容时完整保留原图。Canvas 采用主图与不同尺寸辅助图的结构。
- 智能主体识别、抠图、背景清理和生成式融合尚未接入；不会将预制图片冒充用户上传的生成结果。
- 对应验证：`node prototype/qa/poster-editorial.mjs`，实际 1–6 图输出见 `prototype/qa/editorial-*.png`。

## 微信登录流程

首页先编辑，点击“夸一夸，生成海报”后，在当前页面引导“微信授权并生成”；授权成功自动开始制作。浏览、上传和输入时不提前打断，取消或失败保留草稿，登录过程不扣次数。“我的”保留用户主动登录入口。浏览器仅保存本地交互登录标记，不调用微信、不会读取真实微信身份，也不是安全鉴权机制。正式接入边界与状态见 PRD 第四章。既有账号、草稿、海报及次数未重置。

检查：`node prototype/qa/wechat-login.mjs`。其余业务回归使用已登录夹具，不绕过本用例的登录检查。
